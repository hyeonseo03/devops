# 2주차
## 오늘 배운 내용
- 가상화(서버, 베어메탈/하이퍼바이저/컨테이너 비교)
- WSL2
- 컨테이너 가상화 (Container): 호스트 OS의 커널을 공유하며 리눅스 네임스페이스(격리)와 cgroups(자원 제어) 기술을 활용해 격리 공간을 생성. 구조가 가볍고 배포 속도가 매우 빠름.

### 리눅스 시스템 및 파일 관리 명령어
```bash
# 작업 디렉터리 및 파일 확인
pwd                 # 현재 작업 중인 절대 경로 출력
ls -l               # 권한, 소유자, 크기, 수정시간 등 상세 정보 출력
ls -a               # 숨김 파일(.으로 시작)을 포함한 전체 목록 출력

# 디렉터리 및 파일 제어
mkdir <디렉터리>     # 새 디렉터리 생성
rmdir <디렉터리>     # 비어 있는 디렉터리 삭제
touch <파일명>       # 빈 파일 생성 또는 타임스탬프 갱신
cp <원본> <대상>     # 파일 복사
mv <원본> <대상>     # 파일 이동 또는 이름 변경
rm <파일명>          # 파일 삭제
